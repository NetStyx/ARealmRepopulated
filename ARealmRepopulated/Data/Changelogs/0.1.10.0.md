# Help at Hand

## Functional Changes
- The Changelog tab is now the Info tab. It opens on a short help page with a quick start and a button to open the wiki, and the changelogs are listed below it
- Actors have a new "Snap to surface" option. When it is on (the default), they are placed on the surface they stand on, like the ground or furniture, at the start of every run; turn it off to keep them at exactly the stored height
- Actors have a single size slider now, "Actor scale". Saved scenarios and imported character files keep their sizes

## Bugfixes
- Fixed actors placed slightly inside the ground standing correctly on the first run of a looping scenario, but sinking into the ground from the second run on
- Fixed the height from an actor's appearance having no effect on its size
