# 0.1.5.0 Changelog
Expands actor interactions with head tracking, direct timeline playback, and furniture use while improving pickers, debugging, and internal reliability.

## Functional Changes
- Added the ability for actors to head track the players position
- Added the ability for actors to play existing timelines directly
- Added the ability for actors to sit or sleep on appropriate furniture when they are close enough
- Remember to stand up after you sit.
- Updated the debug ui to not depend on the main window being open
- updated the different pickers to provide more data

## Technical changes
- Removed the custom speech bubble code and switched over to existing implementation
- Removed custom emote code and switched over to existing implementation
- Fixed some issues with character file parsing
