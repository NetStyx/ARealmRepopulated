# NPC Appearances and Steadier Spawns
Adds an NPC appearance picker while improving model handling, scenario loading, and actor spawning stability.

## Functional Changes
- Added an appearance picker for selecting appearances from known NPCs.

## Technical Changes
- Added model scale values to scenario files.
- Improved head-tracking behavior for models that do not support it.
- Prevented a game crash that could occur when spawning an actor on a water surface.
- Fixed an issue where scenarios could be loaded in housing districts on the wrong server.
