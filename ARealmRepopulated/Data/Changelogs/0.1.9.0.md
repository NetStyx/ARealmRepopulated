# Scenarios That Pick Their Moment

Scenarios can now be given conditions, so they only bring their actors out at the right hour, in the right weather, or now and then by chance.

## Functional Changes
- Scenarios can now carry conditions - an Eorzean time window, one or more weathers, or a plain chance - and all of them have to hold before the scenario runs
- A condition can be inverted, for example to run outside a time window or in any weather but the chosen ones
- Actors are taken away again once the current run has finished, so a waiting scenario leaves nobody standing around and frees room for other scenarios
- A running scenario is never cut short; its conditions are only acted on between runs
- The scenario editor and the scenario list both show whether a scenario's conditions currently hold
- Actors can be given a voice, so emotes with a voice line are now heard. It is taken over from character files and picked characters that have one

## Technical Changes
- Reading a scenario file and spawning its actors are now separate steps, so a scenario waiting for its conditions costs no actors
- The Eorzean hour and the current weather are read from the game's own state without hooking or calling into it

## Bugfixes
- Changing the scale, height or hidden gear of a newly added actor no longer changes it for the other newly added actors, or for the next ones added in that session
- `/arrp reload` now reloads the scenarios in the current area instead of opening the configuration window
