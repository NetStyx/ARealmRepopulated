# Consistency is Key

<punchline>

## Functional Changes
- A looping scenario which instantaneously finishes will now be automatically detected and forced to wait an extra second between its runs. A notification is displayed when this happens.
- The first-start introduction can be opened again from the help page in the Info tab.
- A scenario file that cannot be read now shows up in a "Broken files" folder at the top of the scenario list, with the reason in its tooltip. Its actors are taken away until the file is fixed.

## Bugfixes
- Actors now say the voice line of an emote they play right after appearing.
- A scenario imported from the clipboard is now upgraded when it was exported with an older version, the same way scenario files are.
- Saving in the scenario editor no longer conflicts with switching the scenario on or off in the list while the editor was open.
- The checkbox for switching a scenario on or off in the list no longer flickers.
- The "Auto load scenarios" switch in the options now works as intended. With it off, you need to manual reload whenever things change inside your scenario files.
- Editing a scenario that is already open in an editor now brings that editor to the front instead of opening a second one.
- A copy of a scenario file now shows up as its own scenario instead of replacing the original in the list.
- Fixed several typos in the plugin texts.
