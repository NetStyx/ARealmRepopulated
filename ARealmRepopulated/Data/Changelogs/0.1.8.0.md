# Editor Rework and Livelier Actors

Reworks the scenario editor, lets actors sprint or move at a custom speed, open automatic doors, and makes following the player character with their head more reliable.

## Functional Changes
- UI Rework of the scenario editor
- Actors can now sprint, or move at a custom speed, with their steps matched to it
- Automatic doors now open and close for actors
- Reworked the changelog tab into a release list with the selected release's notes beside it

## Technical Changes
- Following the player character with the head no longer hooks into the game, so it is less likely to break on game updates

## Bugfixes
- Fixed actors sometimes not following the player character with their head, or not looking away when the player character left quickly
- Fixed the path preview in the editor disappearing when the camera faced away from part of the path
