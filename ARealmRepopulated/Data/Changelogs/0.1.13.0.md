## Functional Changes
- The Eorzea time condition now takes any minute of the day. Drag the hours or minutes, or double-click to type them.
- A chance now holds its roll for a while. Set how often it is rolled again with "Roll every" in the chance condition.
- The scenario settings have a new Playback tab for looping and the new option "When conditions fail": besides finishing the current run, a scenario can now end immediately or keep running once it has started.
- Each timeline in a Timeline action has a new Wait option. Untick it and the action no longer waits for that timeline, which keeps playing into the following actions, for example a facial expression while the actor walks.
- The timeline list can be filtered by slot and no longer lists entries without a name. It and the NPC preset list scroll smoothly now, even with thousands of entries.

## Bugfixes
- An inverted chance condition no longer shows as not met in the editor header, and a scenario with one that waits endlessly no longer leaves right after it appears.
- The timeline list showed the wrong slot for each animation and marked about half of them as looping. It now shows the slot the animation really plays in and only marks animations that really loop, and an animation for a slot that is already used in the action can no longer be picked.
- A Timeline action that waits forever on a looping animation now counts as waiting endlessly, like a Wait without a duration.
- A Timeline action right after the actor appears no longer loses its animation on the first run of a scenario.
